📡 Assimilation de Données

L'assimilation de données (DA) permet d'intégrer les observations réelles (satellites, stations sol, sondes) dans un modèle numérique ou IA. C'est une brique essentielle dans la prévision météo régionale.

  • 🔁 Méthodes utilisées : 4D-Var, EnKF, hybrid DA
  • 📡 Données : ERA5, AROME, observations satellitaires
  • 🛠 Outils : DART, xDALEC, intégration avec PyTorch
